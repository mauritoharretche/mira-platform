# Definition of Done

A change is Done only when all applicable criteria are met:

- [ ] Acceptance criteria are satisfied.
- [ ] Code follows repository conventions and has no unexplained debug code.
- [ ] Tests cover new behavior and relevant regressions.
- [ ] Formatter, linter, type checks and build pass.
- [ ] Security and privacy review is complete for the change's risk.
- [ ] Accessibility and responsive behavior are checked for UI work.
- [ ] API, schema and event contracts are updated.
- [ ] Migrations have rollout, compatibility and recovery plans.
- [ ] Observability and operational documentation are updated.
- [ ] Public diff contains no secrets or internal information.
- [ ] Pull request received required human review.
- [ ] Deployment or release authorization is recorded when applicable.
