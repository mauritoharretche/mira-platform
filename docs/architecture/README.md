# Architecture

The engineering foundation uses an accepted modular monolith, API-first boundaries, PostgreSQL as its transactional database, and a versioned Python/Django and Next.js stack. This does not approve product scope, cloud hosting, payments, fiscal integrations, personal-data processing, or production deployment.

Accepted ADRs are recorded in [`decision-log.md`](decision-log.md). Superseded decisions remain in the repository for historical context.
